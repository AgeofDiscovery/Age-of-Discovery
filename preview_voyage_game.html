Quick Buttons

바로가기 버튼

실리태번 채팅창 위의 QR바 버튼에 해당한다. 버튼을 누르면 행동이 실행되고, 필요한 경우 새 HTML 결과창이 출력된다.

⚓ 출항

목적지 선택 → 보급 확인 → 항해 이벤트 판정 → 도착/표류/사건 결과 출력.

🏰 항구 탐색

항구 시설 목록 출력. 교역소, 조선소, 술집, 정보상, 성소 중 선택지가 나온다.

🛒 교역

현재 항구의 물품 시세, 보유 화물, 예상 이익을 보여주고 구매/판매를 처리한다.

👥 선원과 대화

선원 또는 주요 인물을 고른다. 관계 기억, 소지품 인지, 로맨스 장면을 이어간다.

📖 항해일지

날짜별 사건, 약속, 소문, 관계 변화를 요약한다. 장기 기억 확인용이다.

📦 화물칸 점검

소지품과 화물 상세창 출력. 쥐, 밀항자, 침수, 파손 같은 이벤트도 확인한다.

🗺 항해도

현재 항구, 다음 항로, 추천 교역 루트, 위험 해역을 지도형 HTML로 보여준다.

🚪 선내 구조

선장실, 주갑판, 의무실, 화물칸 등 장소 버튼을 보여주고 장소 기반 장면을 시작한다.

📋 상태 확인

현재 상태창보다 자세한 선박, 재정, 선원, 식량, 명성, 칭호 정보를 펼친다.

✍ 대필

선택한 문장을 바탕으로 유저 시점의 긴 행동문을 AI가 대신 작성한다.

Blueprints

카라벨(Caravela) 내부 구조

배 그림 자체는 줄이고, 각 구역의 실제 위치감이 살아나도록 장소 버튼만 배치한다. 버튼을 누르면 해당 장소에서 장면이 시작된다.

소형 탐험선 · 시작 배 · 선장실은 선미 쪽, 화물칸은 중앙 하부, 주갑판은 중앙 상부

🧭 선장실

지도, 항해일지, 개인 물품, 비밀 편지가 보관된다. 둘만의 장면이 가장 자연스럽게 시작되는 곳.

⚕ 의무실

부상과 질병을 다룬다. 이네스와의 긴장감 있는 간호 장면에 사용한다.

📦 화물칸

교역품, 보급품, 젖은 화물, 숨겨진 물건을 점검한다. 소지품 기억과 직접 연결된다.

⚓ 주갑판

항해 명령, 날씨 이벤트, 선원 갈등, 갑작스러운 고백이 일어나는 열린 공간.
